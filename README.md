# Análisis de coyuntura: crisis del agua

Presentación interactiva en Slidev sobre la crisis hídrica de Bogotá y Cundinamarca, con visualizaciones ECharts y cartografía GeoJSON.

## Desarrollo local

```bash
npm ci
npm run dev
```

## Publicación

Cada cambio enviado a `main` activa el flujo de GitHub Pages. En el repositorio, configure **Settings → Pages → Source → GitHub Actions**.
